# Simple Mods Manager

**The conflict-aware mod manager for GTA V Enhanced.**

Simple Mods Manager (SMM) installs, updates and organizes your GTA V Enhanced
mods for you: browse mod sites inside the app, download safely (every file is
virus-scanned first), and keep every setup in a switchable **profile** - with
automatic backups and restore points, so one click always brings back a clean,
working game. It ships its own mod loader and script handler, so mods work on
Enhanced without any manual file juggling.

## Download

Grab the latest release from the
[**Releases page**](https://github.com/0x78f1935/SMM/releases/latest) - a
single `SimpleModsManager.exe`, nothing to install. Put it in a folder of your
choice and run it; everything it saves stays in a `SimpleModsManager_data`
folder next to it.
